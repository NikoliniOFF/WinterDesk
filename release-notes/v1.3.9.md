## ❄️ WinterDesk для Windows 1.3.9

**Скачать:** `WinterDesk-1.3.9-win64.zip` ниже (или постоянная ссылка `WinterDesk-win64.zip`). Распакуйте и запустите `WinterDesk.exe`.

### Что нового
- 🔄 Исправлена проверка обновлений: раньше WinterDesk иногда писал, что GitHub недоступен (ошибка 403), потому что обращался к лимитированному API. Теперь версия берётся с обычной страницы выпуска, файлы — из выпуска, а «Что нового» — прямо из репозитория. Если GitHub попросит подождать, WinterDesk тихо повторит попытку сам, без окон с ошибками.
- 🧩 «Другие программы от Nikolini» в «О программе»: HubDesk, PeekDesk, SnapDesk, SpotDesk, DockDesk и IslandDesk с описанием и кнопками «Сайт» и «GitHub». Список обновляется сам, без новой версии WinterDesk, а HubDesk всегда показывается первым. Не нужен — выключите переключатель «Показывать другие программы»: раздел скроется и ничего не будет загружаться.
- 🎨 Новые логотипы программ: SnapDesk, DockDesk, IslandDesk, HubDesk и SpotDesk обновлены — в приложении, на сайте и в README.
- ✨ Всё остальное без изменений: плавность 1.3.8 сохранена.

### Если Windows предупреждает
SmartScreen может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

**Требования:** Windows 10 или 11, 64-бит.
