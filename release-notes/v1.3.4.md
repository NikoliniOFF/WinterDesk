## ❄️ WinterDesk для Windows 1.3.4

**Скачать:** `WinterDesk-1.3.4-win64.zip` ниже (или постоянная ссылка `WinterDesk-win64.zip`). Распакуйте и запустите `WinterDesk.exe`.

### Что нового
- 🎮 Игры на нескольких мониторах: снег прячется на мониторе с игрой без рамки, даже если вы переключились на другой монитор. На остальных мониторах снег продолжает идти.
- 🔋 Если игра или видео заняли все мониторы, WinterDesk почти не нагружает компьютер, пока вы не вернётесь на рабочий стол.
- 🔄 Автообновление надёжнее: если при проверке нет интернета или GitHub не ответил, WinterDesk тихо попробует снова через 5 минут, потом реже. После сна компьютера проверка тоже не пропадёт.
- 🚀 Автозапуск: если папку с программой перенесли, путь автозапуска исправится сам при следующем запуске. Если автозапуск выключили в «Диспетчере задач → Автозагрузка», переключатель в настройках это покажет, а включение в WinterDesk снова его разрешит.
- 📦 Подсказка, если программа запущена прямо из архива: распакуйте её в постоянную папку, иначе автозапуск не сработает.

### Если Windows предупреждает
SmartScreen может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

**Требования:** Windows 10 или 11, 64-бит.
